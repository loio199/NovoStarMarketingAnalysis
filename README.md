## What the main files contain

| File or folder | Purpose |
|---|---|
| `data/raw/` | Original customer, product, order, order-item, campaign, and support-ticket CSV files, plus `DATA_DICTIONARY.md`. |
| `data/processed/` | Cleaned CSV files, including standardized customer countries and order-quality flags. |
| `Notebooks/01_data_audit.ipynb` | Checks missing values, duplicates, keys, dates, campaign attribution, and order-total consistency. |
| `Notebooks/02_data_cleaning.ipynb` | Removes verified exact duplicates, adds data-quality flags, and exports processed datasets. |
| `Notebooks/03_marketing_performance.ipynb` | Calculates sales trends, attributed ROAS, product contribution, returns, customer behavior, and sensitivity scenarios; generates charts and tables. |
| `Notebooks/04_validate_results.ipynb` | Checks formulas, reconciles totals, tests example transactions, and assesses sensitivity to duplicate order-item rows. |
| `src/config.py` | Defines project paths to datasets and output folders. |
| `src/data_loader.py` | Loads raw CSV files and parses dates. |
| `src/data_quality.py` | Reusable data-audit helper functions. |
| `outputs/figures/` | Saved visualizations used in the analysis. |
| `outputs/tables/` | Saved campaign, channel, customer, and other analysis tables. |
| `REPORT.md` | Explains the analytical approach, design decisions, assumptions, validation, tools, AI assistance disclosure and steps to run the project. |
| `pyproject.toml` | Python package configuration and project dependencies. |
| `requirements.txt` | Dependency list for the Python environment. |
| `NovoStar_Marketing_One_Page_Brief` | A One Pager for Business with the final conclusions |
| `.gitignore` | Excludes temporary and environment-specific files from Git. |


## Setup

**Prerequisites:** Git and **Anaconda or Miniconda** must already be installed. Use Anaconda Prompt on Windows or a Conda-enabled terminal.

```bash
# Clone the repository and enter its root directory
git clone <repository-url>
cd NovoStarMarketingAnalysis

# Create and activate the environment
conda create -n novostar python=3.11 -y
conda activate novostar

# Install the project and its dependencies
pip install -e .

# Start Jupyter Notebook from the repository root
jupyter notebook
```

`pip install -e .` installs the dependencies declared in `pyproject.toml` and allows notebooks to import the local `src` package. There is no need to install `requirements.txt` separately when using this method.
